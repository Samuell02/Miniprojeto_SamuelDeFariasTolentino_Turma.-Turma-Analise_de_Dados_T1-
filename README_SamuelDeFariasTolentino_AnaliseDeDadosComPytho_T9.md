


Como executar o projeto:
1.Abra o pycharm na pasta do projeto

2.Aperte com o botão direito no ProjetoSctec.py

3.Aperte em "Run ProjetoSctec", a opção com o triangulo simbolo de play, ou aperte ctrl+shift+f10 enquanto o arquivo está selecionado.


 
No VS Code:
 
 
1.Abra o vscode e aperte em Arquivo > Abrir Pasta, depois escolha a pasta do projeto
 
3.Aperte no ProjetoSctec.py para abrir o arquivo
 
4.Aperte ctrl+shift+p, digite "Python: Select Interpreter" e escolha o python que você instalou

5.abra o terminal (ctrl+') e digite pip install pandas
 
6.Aperte no triangulo de play no canto superior direito, ou aperte ctrl+f5 enquanto o arquivo está aberto, ou digite python ProjetoSctec.py no terminal.
 
 
No Google Colab:
 
1.Entre em colab.research.google.com com sua conta google
 
2.Aperte em "Novo notebook"

3.Aperte no ícone de pasta na barra da esquerda, depois no ícone de upload e envie o ProjetoSctec.py (e o Base_Varejo.csv)

4.digite !pip install pandas na celula antes de rodar 

5.Em uma célula nova digite %run ProjetoSctec.py e aperte shift+enter
